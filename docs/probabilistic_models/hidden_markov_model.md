# Hidden Markov Model (HMM)

A Hidden Markov Model represents a sequence generated by states that cannot be observed directly.

## Model components

- **States**: hidden conditions, such as `Rainy` and `Sunny`.
- **Observations**: visible events, such as `walk`, `shop`, and `clean`.
- **Initial distribution**: probability of each state at time 0.
- **Transition matrix**: probability of moving from one hidden state to another.
- **Emission matrix**: probability of an observation given a hidden state.

The Markov assumption says that the next hidden state depends only on the current state. The observation at a time step depends only on the hidden state at that step.

## Algorithms implemented

1. **Forward** computes the likelihood of an observation sequence by summing over all possible hidden-state paths.
2. **Viterbi** finds the single most likely hidden-state sequence.

Both algorithms use log probabilities to reduce numerical underflow. The implementation validates probability distributions and observation indexes.

## Compile and run

```bash
g++ -std=c++17 -Wall -Wextra -O2 cpp/hidden_markov_model.cpp -o hmm
./hmm
```

The example uses the classic two-state weather model. It prints the observation-sequence likelihood and the most likely hidden-state path.

## Complexity

For (T) observations and (N) hidden states:

- Forward: (O(TN^2)) time and (O(N)) working memory.
- Viterbi: (O(TN^2)) time and (O(TN)) memory for backtracking.

## Scope

This is a discrete HMM with known parameters. It does not train parameters; Baum-Welch (Expectation-Maximization) can be added as a separate extension.
